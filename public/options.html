Open LLM Translator Settings

You only need the API key for the provider of the selected model.

API keys are stored only in chrome.storage.local on this computer and are not synced through Chrome Sync. A saved key is never shown in full again and can't be copied from here. To replace a key, paste a new one; leave a field empty to keep the existing key.

We recommend creating a dedicated API key for this extension and setting a spending limit with the provider: Anthropic, OpenAI, Google.

When translating, the text of the segments to translate, the page title and the URL (domain and path only, no query string) are sent with your API key to the provider of the selected model (Anthropic, OpenAI or Google) and handled under that provider's API terms. Translations are cached on this computer and are not sent anywhere else.

Applies right away. A tab that is already translated switches the next time it is toggled or shows an error. The extension's description on chrome://extensions and in the Chrome Web Store, and the shortcut descriptions on chrome://extensions/shortcuts, always follow the browser's language.

How to use: click the extension icon to open the menu, or press the shortcut (default Alt/Option+A) to toggle translation. You can change shortcuts at chrome://extensions/shortcuts.

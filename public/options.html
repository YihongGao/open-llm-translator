Open LLM Translator 設定

只需要填所選 model 那一家的 API key。

API key 只存在這台電腦的 chrome.storage.local，不會經由 Chrome Sync 同步。

翻譯時，畫面上要翻譯的段落文字、頁面標題和網址（只含網域與路徑，不含查詢字串）會用您的 API key 送到所選 model 的服務商（Anthropic、OpenAI 或 Google），依該服務商的 API 條款處理。譯文會快取在這台電腦，不會送到其他地方。

使用方式：點擴充功能圖示開啟選單，或直接按快捷鍵（預設 Alt/Option+A）切換翻譯。快捷鍵可在 chrome://extensions/shortcuts 修改。

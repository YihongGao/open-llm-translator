Tidepool Notes Basics Prompts About

Internals · 6 min read

Tokens: the unit your model actually sees

Every prompt you send is converted into a sequence of integer IDs before the model reads a word of it. Many of the strange failures you hit in production start at that step.

How text becomes tokens

Most modern tokenizers use byte-pair encoding. Training starts from raw bytes and repeatedly merges the most frequent adjacent pair into a new token, until the vocabulary reaches a target size, often somewhere between 50,000 and 200,000 entries.

Frequent words end up as a single token, usually with the leading space attached, so “ the” and “the” are different IDs. Rare words, typos and long numbers are split into several pieces, and where those splits fall is not always intuitive.

What this explains

Character-level tasks are hard because the model never sees characters. Counting letters or reversing a string means reasoning about pieces it cannot look inside, and arithmetic on long numbers suffers when digits are grouped unevenly.

Whitespace matters too. A stray trailing space at the end of a prompt can shift the output, because it changes which token the model expects to come next.

Tip: before debugging a strange output, run the prompt through the model's own tokenizer and look at the actual pieces.

01網頁

原文和譯文放在一起讀

在英文網頁按 Alt+A，譯文插在每段原文下面，原文一個字都不少。這樣讀有兩個好處。

  • 翻錯了，你看得出來

    覺得哪句譯文怪怪的，往上看一眼原文就知道。不用切分頁，也不用猜。

  • 練英文閱讀

    想練英文，就先讀原文，卡住了再看下一行的中文。英文一直都在，不會整頁被換成中文。

  • 開發者不收任何費用

    Open LLM Translator 免費使用，不用訂閱，也不用註冊帳號。

  • 費用來自你用的 AI

    翻譯用你自己的 API key，由 AI 服務商照用量向你收費，錢不經過我們。這個月沒翻譯，就一毛都不用付。

  • 支援主流 LLM 服務

一篇文章、一本書、一個月，各要多少錢

以下是英文翻成繁體中文的大概費用，用預設的 Claude Haiku 和高一級的 Claude Sonnet 來算。

  • 同一個網站上翻過的文字會存在你的電腦裡，再看一次不會重複計費。
  • 實測：一整頁技術文件（約 75 段）用 Haiku 翻，約 US$0.0013。
  • GPT-6 Luna 和 Haiku 同價；Gemini 3.5 Flash-Lite 大約是 Haiku 的 4 到 5 倍。完整的 model 和價格列表

估算方式：每個英文字約 1.3 個 token；每個英文字約譯成 1.5 個中文字，每個中文字約 1 到 2 個 token。翻譯指令有快取，增加的費用很少。以 2026 年 11 月的 API 價格計算（每百萬 token：Haiku input US$0.10、output US$0.50；Sonnet US$2、US$10）。實際費用依文章內容而定。

04安全

API key 不用上傳，只留在你的電腦

  • 網頁讀不到你的 key

    key 不會跟著 Chrome 同步，網頁和其他擴充功能也讀不到。

  • 沒有我們的伺服器

    你按下翻譯，瀏覽器才把畫面上的段落、頁面標題和網址直接送到你選的服務商。我們不蒐集任何使用資料。

  • 程式碼公開

    以 Apache-2.0 授權放在 GitHub，誰都可以看。

想多一層保障，可以替這個擴充功能另開一把專用的 key，並在服務商那邊設定費用上限。

05安裝

三個步驟，開始雙語閱讀

  1. 安裝擴充功能

    從 Chrome 線上應用程式商店安裝。

    加到 Chrome

  2. 貼上你的 API key

    在擴充功能圖示上按右鍵，選「選項」。選好 model，貼上那一家的 key，按「測試連線」。還沒有 key 的話，到 Anthropic、OpenAI 或 Google AI Studio 申請。

  3. 在英文網頁按 Alt+A

    或點擴充功能圖示，按「翻譯此頁」。再按一次就只看原文。

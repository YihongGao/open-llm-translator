Token：模型真正看到的單位

你送出的每個 prompt，在模型讀到任何一個字之前，都會先轉成一串整數 ID。你在正式環境遇到的許多怪問題，都是從這一步開始的。

文字怎麼變成 token

現在大多數的 tokenizer 用的是 byte-pair encoding（BPE）。訓練時從原始位元組開始，反覆把最常相鄰出現的一對合併成新的 token，直到詞彙表達到目標大小，通常在 5 萬到 20 萬之間。

常見的英文單字最後會變成單一 token，而且通常連著前面的空白，所以「 the」和「the」是不同的 ID。少見的字、錯字和長數字會被切成好幾塊，切在哪裡也不一定合乎直覺。

這能解釋什麼

字元層級的任務很難，因為模型從來沒看過字元。數字母、把字串倒過來，都得對著看不到內部的區塊推理；長數字的算術也會因為數字被切得長短不一而出錯。

空白也有影響。prompt 結尾多一個空白，就可能改變輸出，因為它改變了模型預期接下來出現的 token。

小提醒：遇到奇怪的輸出，先把 prompt 丟進該模型自己的 tokenizer，看看實際被切成哪些塊。

01Web

Read the original and the translation together

Press Alt+A on a page in another language. Each translation goes under its paragraph, and the original stays exactly as it was.

  • Spot a bad translation

    If a line reads oddly, glance up at the original. No switching tabs, no guessing.

  • Practice a language you're learning

    Learning Chinese, Japanese or Korean? Read the original first, and drop to the English line when you get stuck. The original never goes away; the English sits underneath it.

02Video

Bilingual YouTube subtitles

Press Alt+S on a YouTube video. The original and translated subtitles appear together in the player, including in full screen.

Listen to the original and glance at the English line when you lose the thread. It doubles as listening practice.

03Cost

The extension is free. You pay only when you translate with AI.

  • The developer charges nothing

    Open LLM Translator is free to use, with no subscription and no account.

  • You pay for the AI you use

    Translations run on your own API key. The AI provider bills you for what you use, and the money never passes through us. A month without translating costs nothing.

  • Works with the major LLM providers

    Anthropic (Claude), OpenAI (GPT) or Google (Gemini). You only need one.

What an article, a book or a month costs

Rough costs of translating Chinese, Japanese or Korean into English, with the default Claude Haiku and the next tier up, Claude Sonnet.

  • Translations are cached on your computer, so the same text on the same site isn't billed again.
  • Measured: a full page of technical documentation (about 75 paragraphs) cost about US$0.0013 with Haiku.
  • GPT-6 Luna is priced the same as Haiku; Gemini 3.5 Flash-Lite costs about 4 to 5 times as much. Full list of models and prices

How these are estimated: one English word corresponds to about 1.5 Chinese, Japanese or Korean characters, each character is 1 to 2 tokens, and each English word is about 1.3 tokens. The translation instructions are cached, so they add little. Prices are November 2026 API prices per million tokens: Haiku input US$0.10 and output US$0.50; Sonnet US$2 and US$10. Actual cost depends on the text.

04Safety

Your API key stays on your computer. It goes only to your AI provider.

  • Web pages can't read your key

    The key does not sync through Chrome, and neither web pages nor other extensions can read it.

  • No server in between

    Nothing is sent until you translate. Then your browser sends the paragraphs on screen, the page title and the page address (without the query string) straight to the provider you chose. We collect no analytics or usage data.

  • Open source

    The code is on GitHub under the Apache-2.0 license, for anyone to read.

For an extra layer of safety, create a separate key just for this extension and set a spending limit with your provider.

05Install

Three steps to bilingual reading

  1. Install the extension

    Install it from the Chrome Web Store.

    Add to Chrome

  2. Paste your API key

    Right-click the extension icon and choose Options. Pick a model, paste that provider's key and click Test connection. No key yet? Get one from Anthropic, OpenAI or Google AI Studio.

  3. Press Alt+A on a page in another language

    Or click the extension icon and choose Translate this page. Press Alt+A again to show only the original. Translations are in your browser's language by default, and you can change that in Options.
